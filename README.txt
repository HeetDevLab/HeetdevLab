HEETDEVLAB — MAIN WEBSITE / ARROW EDITION
========================================
A responsive independent-software-studio homepage using the same dark editorial visual identity as the personal portfolio, with product and studio content kept separate.

FILES
- index.html   Studio homepage and metadata
- style.css    Responsive design system and page layout
- script.js    Mobile navigation, scroll progress, reveal motion and pointer-arrow trail
- favicon.svg  New studio favicon

PUBLISH TO THE MAIN GITHUB PAGES REPOSITORY
Repository: HeetDevLab/HeetDevLab.github.io
1. Back up the current root files.
2. Upload/replace only index.html, style.css, script.js and favicon.svg in the repository root.
3. Keep all existing product folders/pages and other files, including Sentinex, Sentinex-Vault, Webtools, Blog, portfolio, favicon.png, icon.jpg, robots.txt, sitemap.xml, google verification HTML and service-worker.js.
4. Commit the changes to main and open https://heetdevlab.github.io/ after Pages rebuilds.

INTERACTIONS
- Desktop pointer movement creates a restrained directional-arrow trail.
- Mobile navigation opens as an overlay panel.
- Scroll progress and section reveal effects are included.
- prefers-reduced-motion disables non-essential motion.
